mfreg

PURPOSE

Interface gráfica para análise dos padrões de escoamento.

SYNOPSIS

function mfreg

DESCRIPTION 

 Interface gráfica para análise dos padrões de escoamento.

CROSS-REFERENCE INFORMATION

This function calls:
  • arvore_dados Função que compõe a estrutura dos dados de entrada e a arvore de dados
  • determinaAlfaEstavel Função que determina frações de área para modelos de Taitel, Pots e Zuber
  • identificaRegimeEstavel Função que executa a IPE e gera as variáveis identificadoras para fraçõe
This function is called by:
  • mfsim Interface gráfica para tela de abertura do programa.
