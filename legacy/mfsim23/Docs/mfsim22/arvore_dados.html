arvore_dados

PURPOSE

Função que compõe a estrutura dos dados de entrada e a arvore de dados

SYNOPSIS

function [detalhesVariaveis, valoresDefault] = arvore_dados

DESCRIPTION 

 Função que compõe a estrutura dos dados de entrada e a arvore de dados
 contendo as características de todas as informações necessárias para
 executar o simulador

CROSS-REFERENCE INFORMATION

This function calls:
This function is called by:
  • mfreg Interface gráfica para análise dos padrões de escoamento.
  • mfsim_entrada Interface gráfica para simulação de redes de escoamento bifásico.
  • mfsim_saida Interface gráfica para resultados de escoamento bifásico.
