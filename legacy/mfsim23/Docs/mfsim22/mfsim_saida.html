mfsim_saida

PURPOSE

Interface gráfica para resultados de escoamento bifásico.

SYNOPSIS

function mfsim_saida

DESCRIPTION 

 Interface gráfica para resultados de escoamento bifásico.

CROSS-REFERENCE INFORMATION

This function calls:
  • arvore_dados Função que compõe a estrutura dos dados de entrada e a arvore de dados
  • arvore_saidas Função que compõe os nomes de todas as saídas do modelo
  • plota_resultados Função que plota os resultados da simulação.
This function is called by:
  • mfsim Interface gráfica para tela de abertura do programa.
  • mfsim_entrada Interface gráfica para simulação de redes de escoamento bifásico.
