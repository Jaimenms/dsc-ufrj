mfsim_entrada

PURPOSE

Interface gráfica para simulação de redes de escoamento bifásico.

SYNOPSIS

function mfsim_entrada

DESCRIPTION 

 Interface gráfica para simulação de redes de escoamento bifásico.

CROSS-REFERENCE INFORMATION

This function calls:
  • analisador Função que permite analisar os autovalores da matriz jacobiana das
  • arvore_dados Função que compõe a estrutura dos dados de entrada e a arvore de dados
  • arvore_saidas Função que compõe os nomes de todas as saídas do modelo
  • mfsim_entrada Interface gráfica para simulação de redes de escoamento bifásico.
  • mfsim_saida Interface gráfica para resultados de escoamento bifásico.
  • simulador Função que executa a simulação bifásica de escoamento em redes de dutos.
This function is called by:
  • mfsim Interface gráfica para tela de abertura do programa.
  • mfsim_entrada Interface gráfica para simulação de redes de escoamento bifásico.
